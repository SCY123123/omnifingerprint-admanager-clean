# 需求文档 - 创建主页功能

## 1. 功能概述
在广告管理系统中增加“创建主页”功能，允许用户为选中的浏览器配置批量创建 Facebook 公共主页（Page）。

> **⚠️ 核心架构澄清：Puppeteer 作为本地客户端**
> 所有涉及真实浏览器交互（如本功能中的 Puppeteer 自动化）的执行程序，**仅作为本地客户端程序**运行。
> 严禁将 Puppeteer 服务（`puppeteer-api-server.js` 等）部署到云端服务器。云端仅部署前端页面与存储后端。

## 2. 核心需求
### 2.1 主页弹出菜单
- **名称设置**：支持开启“随机名称”或“自定义名称”。随机名称应具有一定的可读性和多样性。
- **类别设置**：支持选择主页类别（如：Digital Creator, Business Service 等）。
- **图片上传**：可选上传“头像”和“背景图”。
- **域名/网站设置**：支持设置主页的关联域名或网站。

### 2.2 自动化执行
- **批量操作**：支持对选中的多个配置同时发起创建任务。
- **真实执行**：通过 Puppeteer 自动化脚本在对应的浏览器实例中模拟真实用户操作，完成主页创建过程。
- **资产同步**：获取信息时需同步显示所有关键字段，包括：国家、BM、BM数量、Page数量、花费、额度、账单、门槛、卡片等。
- **并发性能**：系统支持多浏览器并发启动（默认 3 个），优化启动队列以实现“零卡顿”体验。
- **反馈机制**：任务提交后应给予用户明确的反馈，告知已启动的任务数量。
- **自动填充登录**：浏览器启动后，系统将自动检测登录页面并尝试填充账号密码，支持手动触发重新填充。
- **AI 助手对话**：导航栏集成 AI 对话窗口，支持通过自然语言指令执行自动化操作（如启动浏览器）。

## 9. Facebook 广告发布自动化
- **核心功能**：
    - **目标地址**：自动跳转至 Facebook 广告管理工具。
    - **双模式发布**：
        - **API 发布**：支持通过 Graph API 快速发布广告，提升效率与成功率。
        - **自动化模拟**：支持通过 Puppeteer 模拟人工操作发布。
    - **全链路自动化**：自动唤起本地 Puppeteer 浏览器（模拟模式）或调用接口（API 模式）执行广告系列、广告组和广告的创建。
    - **网络回退策略**：当本机系统网络栈无法直连 `graph.facebook.com:443` 时，API 发布必须自动切换到已启动浏览器的网络上下文继续请求，避免因 `curl code 28` 导致整条发布链路中断。
    - **内容配置**：支持设置广告名称、预算、投放时间、素材（图片/视频）、文案等。
    - **受众设置**：支持设置投放国家/地区、年龄范围、性别以及广告版位（自动/手动）。
    - **状态同步**：发布成功后自动同步广告 ID 和状态回数据库。

## 10. 性能与稳定性要求 (Performance & Stability Requirements)
- **非阻塞启动**：点击“启动”后，系统必须立即响应并显示启动中状态，不得因页面加载慢而导致 UI 假死。
- **异常鲁棒性**：
  - 自动修复数据库缺失字段（如 `account_name`）。
  - 自动清理残留的浏览器锁定文件（SingletonLock）。
  - 对耗时网络任务（如注入 Cookie）设置强制超时保护。

## 4. 约束与规范
- 必须保持中文对话。
- 严格执行技术文档规范。
### 4.2 部署规范
- **项目隔离规范**：所有部署和运维操作必须严格限制在当前项目目录下，禁止跨目录操作其它服务器路径的文件。
- **数据库命名规范**：数据库文件名统一且固定为 `omnifingerprint.db`。
- **构建排除规范**：`browser-profiles/` 目录仅供本地客户端使用，严禁参与任何前端构建过程。
- **Cloudflare 全栈部署**：支持将前端和 API 后端整体部署到 Cloudflare Pages，并使用 D1 数据库。通过后端代理机制解决跨域 (CORS) 问题。
- **逻辑闭环**：所有前端发起的请求（包括对本地 Puppeteer 的控制）必须由对应的 Pages Functions API 进行转发或处理。

## 6. 安全加固 (Security Hardening)
- **API 响应脱敏**：后端 API 在返回用户列表或用户信息时，必须显式移除 `password_hash` 和内部 Token 字段，防止敏感信息泄露。
- **本地服务鉴权**：本地 Puppeteer 服务启用 `X-Api-Secret` 校验机制。云端 Pages Functions 与前端在调用本地服务时必须携带匹配的密钥。
- **私有网络访问 (PNA)**：本地服务必须正确响应预检请求 (OPTIONS)，并携带 `Access-Control-Allow-Private-Network: true` 响应头，以允许 HTTPS 网页访问本地 HTTP 服务。
- **RBAC 代理校验**：云端 Puppeteer 代理接口 (`/api/puppeteer/*`) 必须实时核验操作者权限，禁止跨团队或越权控制他人浏览器。
- **越权漏洞防护 (IDOR Protection)**：所有数据写入、更新和删除接口均在数据库层强制执行 `user_id` 校验，防止用户通过伪造 ID 篡改他人数据（如配置信息、广告账号状态等）。

## 5. 多级团队与权限系统 (RBAC & Team Management)
- **核心角色**：
  - **超级管理员 (SuperAdmin)**：拥有最高权限，可管理所有用户、全局数据、系统设置及订阅时长。
  - **团队长 (Admin)**：每个用户默认即为管理员。可管理归属其下的团队成员，指定成员的层级身份（Admin/User）。
  - **执行员 (User)**：由管理员创建，负责具体的操作任务。
- **数据隔离**：
  - **层级查看**：团队长可查看其团队内所有成员的数据（配置、广告账号、主页等）。
- **权限指定**：团队长可指定成员的数据查看权限（全部可见 `full`、仅限自己 `own`）。
  - **全部可见 (Full)**：成员可查看团队长及团队内所有成员的数据。
  - **仅限自己 (Own/Self)**：成员仅能查看由其自己创建或归属于其名下的数据。
- **成员添加**：支持“通过邮箱添加成员”，可将已有注册用户邀请并加入当前团队长名下。支持指定被添加成员在团队内的角色（Admin/User）。
- **多管理员支持**：团队内支持存在多个 Admin 角色。所有具有 Admin 角色或被指定为 `full` 权限的成员均拥有团队级数据视野。
- **全局视图**：超级管理员可跨团队查看所有数据。
- **配置分享**：任何用户均可选中多个配置，通过邮箱分享给系统内其他用户，分享后接收者将获得配置的独立副本。
- **分享接口约束**：`POST /api/profiles/share` 必须命中独立分享接口，不得被 `/api/profiles/:id` 之类的通配详情路由抢占；分享成功提示必须以真实写入结果为准。
- **注册机制**：新注册用户默认角色为“团队长 (Admin)”，拥有独立的团队管理权限。
- **订阅管理**：支持设置用户的订阅到期时间，到期后锁定相关操作权限。
- **安全性**：邮箱作为唯一标识，强制要求填写以防止名称重复导致的数据冲突。

## 7. 私有永久邮箱系统 (Private Email System)
- **核心功能**：
    - **私有域名**：基于 Cloudflare Email Routing，提供你自有域名的专属收信域名。
    - **永久存储**：所有邮件直接写入 D1 数据库，实现永久存储。
    - **无密码访问**：彻底弃用第三方临时邮箱（如 Mail.tm），系统自动分配与管理，无需密码即可安全读取。
    - **直接可编辑**：活跃邮箱地址在前端 UI 中支持直接点击编辑。
    - **地址列表导航**：邮件列表左侧新增“地址侧边栏”，在私有模式下显示所有活跃地址及邮件统计，在公共模式下显示本地历史记录，均支持显示每个地址的初始创建时间。
- **稳定性保障**：
    - **架构分离**：Email Worker 独立部署，专门处理 Cloudflare 邮件触发器并直接写入数据库，提升性能和可靠性。
    - **实时监控**：自动轮询邮件列表，支持手动刷新，并与自动化注册流程无缝衔接。

## 8. TikTok Ads 自动化批量注册
- **核心功能**：
    - **目标地址**：自动跳转至 TikTok Ads 注册页 `https://ads.tiktok.com/i18n/signup/`。
    - **一键批量注册**：在账号列表页支持“TikTok 批量注册”功能，可自由选择生成数量。
    - **选中项立即执行**：支持针对列表中已选中的账号执行“立即开始执行注册”操作，复用已有配置。
    - **自动分配公共邮箱**：系统自动调用 Mail.tm API 分配公共临时邮箱并生成密码（私有域名作为备选）。
    - **全链路自动化**：自动唤起本地 Puppeteer 浏览器，模拟用户填写邮箱、密码，并自动查询 Mail.tm API 提取验证码完成验证。
    - **全链路闭环同步**：注册成功后，系统自动提取浏览器当前 Cookie，并连同分配的邮箱、密码一并回写同步到 Cloudflare D1 数据库，实现账号“即注即用”。
    - **UI/UX 偏好**：
    - 在账号列表针对 TikTok 平台显示专用的操作入口。
    - 执行面板动态适配“批量新建”或“选定执行”模式。
